ELI — Brand and name license

ELI's code is free software under **AGPLv3** — copy it, modify it, audit it, distribute it. That license covers the code. It does not cover the name "ELI" or its logo.

## Rules for forks and derivative versions

Anyone building on this code to launch their own version must:

1. **Use their own name and logo.** "ELI" and its logo, or anything that could be confused with them, cannot appear on a fork.
2. **Keep Solidaria honest, if kept at all.** Removing the Solidaria tab is not required. But if a fork keeps it, it must operate under the same distribution, deadline, and transparency rules described in `SOLIDARIA.md` — it cannot be called "Solidaria" while working differently, and the fund can never be redirected to a third party.
3. **Not claim to be the official continuation of ELI.** Reusing this code doesn't inherit the original project's legitimacy.

## Why this exists

Free code and a protected name aren't a contradiction — they're two different questions. Anyone can build on ELI's work; not anyone can call it ELI. This keeps the name meaning something specific (this architecture, this fund, these rules) instead of becoming a generic label attached to whatever a fork decides to do.

## Future foundation

If the community sets up a non-profit foundation to steward the project (see the README's "Governance and future"), a free, perpetual license to use the "ELI" name and logo is intended to pass to that foundation, contingent on it maintaining the project's core philosophy — no ads on the Wall outside Solidaria funding, no diversion of Solidaria's money, no reintroduction of personal data requirements for identity.

# ELI — Licencia de marca y nombre

El código de ELI es software libre bajo **AGPLv3** — cópialo, modifícalo, audítalo, distribúyelo. Esa licencia cubre el código. No cubre el nombre "ELI" ni su logo.

## Reglas para forks y versiones derivadas

Cualquiera que construya sobre este código para lanzar su propia versión debe:

1. **Usar su propio nombre y logo.** "ELI" y su logo, o cualquier cosa que pueda confundirse con ellos, no pueden aparecer en un fork.
2. **Mantener Solidaria honesta, si se conserva.** Quitar la pestaña Solidaria no es obligatorio. Pero si un fork la mantiene, debe funcionar bajo las mismas reglas de reparto, plazos y transparencia descritas en `SOLIDARIA.md` — no puede llamarse "Solidaria" y funcionar de otra forma, y el fondo nunca puede redirigirse a un tercero.
3. **No presentarse como la continuación oficial de ELI.** Reutilizar este código no hereda la legitimidad del proyecto original.

## Por qué existe esto

Código libre y nombre protegido no son una contradicción — son dos preguntas distintas. Cualquiera puede construir sobre el trabajo de ELI; no cualquiera puede llamarlo ELI. Esto mantiene que el nombre siga significando algo concreto (esta arquitectura, este fondo, estas reglas) en vez de convertirse en una etiqueta genérica pegada a lo que decida hacer cada fork.

## Futura fundación

Si la comunidad constituye una fundación sin ánimo de lucro para gestionar el proyecto (ver "Gobernanza y futuro" en el README), la intención es que una licencia gratuita y perpetua para usar el nombre "ELI" y su logo pase a esa fundación, condicionada a que mantenga la filosofía central del proyecto — sin anuncios en el Muro fuera de la financiación de Solidaria, sin desviar el dinero de Solidaria, sin reintroducir la exigencia de datos personales para la identidad.
